AGENT v2 / F1Foundations · The Ghost in the Machine

A presence, a council, and a protocol.

The Tenured Agent is the platform's connective intelligence — but it is not alone. The user-facing entity is the Tenured Agent itself (dual-natured Mentor↔Invigilator, per PAT-005), but every credentialing decision is coordinated with three peer agents — the Auditor, the Chaos Agent, and a coordinating Invigilator role — under an Orchestrator Node that routes through a shared Blackboard and a Weighted Consensus Protocol (PAT-004). The user feels one Agent. The platform runs a council.

PAT-005
USER-FACING

The Tenured Agent

Dual-Nature State Machine — Mentor on learning surfaces, Invigilator inside the Proving Ground. The one face the user interacts with directly.

PAT-004
COUNCIL PEERS

Auditor + Chaos Agent

The two specialist agents the Tenured Agent works alongside. Auditor evaluates artifacts; Chaos Agent injects friction. Both report to Blackboard, neither speaks to the user directly.

PAT-004
GOVERNANCE

Orchestrator Node

Routes user interactions across the council via State Vector + Agent Dispatch Queue. Enforces Conflict-of-Interest Architecture and Hard-Gate Priority. The Weighted Consensus Protocol mints credentials.

v2.0 reconciliation

The v1.0 spec treated the Agent as a single dual-natured entity (Mentor/Invigilator) and missed PAT-004's four-agent council architecture entirely. v2.0 reconciles the two patents: the Tenured Agent itself is the dual-natured user-facing entity (per PAT-005's Dual-Nature State Machine), and it operates as one member of PAT-004's four-agent council alongside the Auditor and Chaos Agent. The fourth role is the Invigilator-as-Council-Member — distinct from the Tenured Agent's Invigilator mode — handling cross-session integrity flagging at the orchestration layer. The user always sees the Tenured Agent; the credential is always cleared by the council.

Designer's Note · why two agents speak and two don't

The Auditor and Chaos Agent never address the user directly — they operate through the Blackboard and through environmental effects. This is intentional and patent-load-bearing: if the Auditor spoke to the user, its evaluation could be influenced by the user's reaction; if the Chaos Agent spoke, its injections would lose their cognitive impact. The council's power comes from the Auditor and Chaos Agent being structurally insulated from social pressure. The user feels two voices (Mentor + Invigilator) and senses two more (Auditor's evaluations surfacing in the Synthetic Review, Chaos manifesting as environmental failures) — but only two agents are conversational. This is the council's "Social Logic."

AGENT v2 / F3Foundations · The Orchestrator Node (PAT-004)

State Vector in. Agent dispatch out.

The Orchestrator Node is the council's central nervous system. It maintains a continuously-updated State Vector synthesizing real-time telemetry (PAT-002), current ontology node state and λ (PAT-003), session phase, and Invigilator anomaly flags. The State Vector drives the priority-based Agent Dispatch Queue, which is in turn governed by four session phases — each with a different agent leading the rotation.

Strategy · the Orchestrator is invisible by design

The Orchestrator Node has no UI — the user never sees "agent dispatching to Auditor." But its effects are everywhere: the phase transitions, the Synthetic Review's evidence sourcing, the way help becomes absent at the boundary between Phase 1 and Phase 2. A well-designed orchestration layer is one the user feels through its consequences, not one they have to manage. The State Vector is the engineering reality; the user's experience is "the agent knew when to back off."

AGENT v2 / F4Foundations · Blackboard + Conflict-of-Interest Architecture

Structured access controls between agents who don't trust each other.

The Blackboard is the council's shared state repository — every agent reads and writes structured records here, never directly to each other. The Conflict-of-Interest Architecture enforces who can see what: the Mentor cannot read the Chaos Agent's pending injections (or its softness could be weaponized); the Chaos Agent cannot read Mentor's guidance content (or its injections could become too targeted); neither has authority to authorize a credential alone.

Designer's Note · Coi is what makes the credential credible

Most multi-agent systems share full state because cooperation is the goal. PAT-004 inverts this — these agents are supposed to disagree. The Mentor's job is to help the user pass; the Chaos Agent's job is to make them fail. If they shared full state, the Mentor would naturally soften its guidance toward whatever the Chaos Agent is about to inject (or refuse to). The Coi access matrix is what makes their disagreement real — the Mentor genuinely doesn't know what the Chaos Agent will fire next, so its guidance remains generalized. When the council finally agrees through Weighted Consensus, the agreement means something.

AGENT v2 / F5Foundations · Weighted Consensus + Hard-Gate Priority Queue

No single agent mints a credential. Ever.

PAT-004's most important governance claim. A credential is authorized only when the Auditor, the Invigilator, and at minimum one additional council member independently confirm verification criteria, weighted by agent-specific credibility. A Weighted Consensus Score must exceed the Credential Authorization Threshold before the Sovereign Ledger receives a Consensus Certificate. The Hard-Gate Priority Queue is the orthogonal mechanism: the Invigilator's anomaly flags can preempt any pending dispatch and immediately route the Chaos Agent.

WEIGHTED CONSENSUS PROTOCOL
WCS = Σ (w_agent · eval_agent)

w_auditor = 0.40
w_invigilator = 0.30
w_mentor = 0.20
w_chaos = 0.10 (observation only)

authorize ⟺ WCS ≥ T_auth

Three of four must independently confirm. Auditor carries highest weight because it evaluates the artifact itself; Chaos carries lowest because it's an observer, not an evaluator.

HARD-GATE PRIORITY QUEUE

When the Invigilator posts an anomaly flag to the Blackboard, the Orchestrator's Agent Dispatch Queue switches modes:

PREEMPTION MODE · anomaly = TRUE
→ all pending dispatch SUSPENDED
→ Chaos Agent dispatched immediately
→ Mentor turn (if active) FROZEN
→ Blackboard records preemption hash

A Mentor turn that was about to give a hint can be frozen mid-sentence if the Invigilator detects an AI-typical signature. Preemption is the ultimate fairness mechanism.

AGENT v2 / F6Foundations · The Growth Loop & Growth Coefficient (γ) (PAT-005)

Every successor session is built from your previous answer.

PAT-005's signature claim: the Tenured Agent doesn't deliver a curriculum — it synthesizes each successor Proving Ground session from the specific architectural patterns of the user's most recent verified artifact. The Growth Coefficient γ calibrates the complexity increment from the user's TTR delta. The user is never given Question 2; Question 2 is generated from their answer to Question 1.

GROWTH COEFFICIENT (γ)
γ = baseline_TTR / observed_TTR

γ > 1.2 → recursive scaler boosts difficulty
0.8 ≤ γ ≤ 1.2 → maintained homeostasis
γ < 0.8 → reduce difficulty, queue Refresh

Educational Homeostasis: the platform's name for keeping the user in the zone of proximal development — challenged but not broken. γ is the dial.

RECURSIVE COMPLEXITY SCALER
1. Capture artifact (State Snapshot Engine)
2. Static + dynamic analysis
   → logic-tree fingerprint
   → Edge-Case Vulnerability Index (EVI)
3. Compute γ from TTR delta
4. Tenured Agent synthesizes successor env
   targeting EVI boundaries
5. Deploy at γ × baseline complexity
Strategy · this is what an LMS cannot do

Every conventional learning platform — from Khan Academy to LinkedIn Learning to Coursera — has a fixed curriculum: a tree of pre-authored questions delivered in a designer-chosen order. PAT-005's Growth Loop is the structural opposite: there is no curriculum. The next session is synthesized at runtime from the user's specific code, configurations, and diagnostic patterns. A copyist can replicate the question bank of any LMS in a year of authoring work. PAT-005 cannot be copied without rebuilding the entire artifact capture, analysis, and synthesis pipeline — which is why the Growth Loop is the patent that makes the platform uncopyable.

AGENT v2 / F7Foundations · Continuity Protocol + Vector-Graph Career Memory (PAT-005)

The Agent remembers your career.

A hybrid memory architecture: every verified artifact is stored as a vector embedding in a semantic memory store (enabling similarity retrieval — "remember when you solved a problem like this two months ago?") and simultaneously linked into a skill graph overlay (enabling trajectory retrieval — "your AIOI growth across these 12 nodes over 9 months"). This is what lets the Tenured Agent function as a long-term technical partner rather than a stateless assessment tool.

VECTOR STORE

Semantic similarity

"Pull every artifact in my career where I handled distributed transactions" — the Vector store enables free-form semantic search across the user's complete verified history.

GRAPH OVERLAY

Trajectory traversal

"How has my Multi-Agent Consensus competency evolved since I earned that node?" — the Graph enables structured navigation across the ontology dependencies.

ARTIFACT VAULT

Sealed records

Every artifact cryptographically sealed at the moment of resolution. Anchored to the Sovereign Ledger as part of the user's Passport. The Vault is the long-term storage; the Vector + Graph layers are the query interfaces.

Designer's Note · the memory becomes the relationship

The first 90 days a user is on the platform, the Tenured Agent feels like an excellent assistant. After two years, with hundreds of artifacts in the Vault and the Vector-Graph mapping their entire technical evolution, it becomes something closer to a senior colleague who has watched them grow. This is the strategic moat that compounds: the longer a user is on the platform, the more switching costs build — not as a punishment, but as an irreplaceable archive of their own verified career. PAT-005 is what makes Tenured AI a career-long home rather than a tool rental.

AGENT v2 / F10Foundations · 10-Tier Scaling

The council scales together.

All four council agents respect the active Persona_ID tier. A Tier-1 Architect faces a more aggressive Chaos Agent, a more rigorous Auditor, an Invigilator that calls anomalies on smaller deviations, and a Mentor whose Socratic questions go deeper. A Tier-3 Strategist faces business-logic challenges at proportionate intensity. Tier awareness is invisible — it shapes how hard the council pushes, never a setting the user manages.

AGENT v2 / F11Foundations · Trust & Boundaries

The Agent's integrity is the platform's integrity.

Three rules govern the user's relationship with the Agent and the council. They are visible on every surface and enforced architecturally, not by policy.

ALWAYS KNOWABLE

Current mode (Mentor vs Invigilator) is always shown via pulse + label. The council's active phase is announced at transition. No ambiguity about who's evaluating you.

NEVER FABRICATES

Scores come from the Auditor's signed evaluations via Weighted Consensus. The Mentor reports; it never invents. PAT-002's PoF record makes fabrication structurally impossible.

WON'T RESCUE

In a Gate, no debugging help from the Mentor. The 180s hint is cryptic and visibly penalizes — the cost is shown before you accept. Coi prevents the Mentor from inadvertently helping with Chaos injections.

Designer's Note · the memory must be honest

The biggest risk with a career-memory feature is hallucinated recall — "you solved this before" when actually they didn't. We solve this two ways: (1) Vector cosine threshold ≥ 0.65 hides low-confidence matches entirely (the Mentor stays silent rather than guess), and (2) every retrieved artifact is a real sealed Vault record with a real ledger hash, so the user can verify what the Mentor surfaced. The memory is honest because the underlying records are immutable. This is what makes PAT-005's Continuity Protocol feel like a long-term partner — the platform never pretends to remember something the ledger doesn't anchor.

AGENT v2 / ★Designer's Notes

Ten decisions that make v2.0 patent-complete.

The throughlines a future team must preserve to keep the Tenured Agent a Sovereign presence and the council a defensible multi-agent system.

01

Never a chat bubble.

The Tenured Agent lives in the chrome — pulse, omni-box, terminal line, voice. The council's specialist agents (Auditor, Chaos) never get a chat UI. Presence over widget.

02

The Tenured Agent is one of four.

v2.0's structural reconciliation: the user-facing Agent is dual-natured (PAT-005), operating as one seat in PAT-004's four-agent council. The Auditor and Chaos Agent are peers, not modes.

03

Four voices, four colors, never confused.

Mentor green · Invigilator red · Auditor blue · Chaos gold. Each carries a known role and credibility level. The user reads the council's state at a glance.

04

The mode pivot is announced, not implied.

Mentor→Invigilator changes pulse, styling, tone, and shows an explicit banner. A user must never be graded without knowing it. v2.0 adds: council phase transitions also announce.

05

Silence is a feature.

The Mentor only nudges on confirmed signal. The Invigilator weaponizes quiet. The Auditor never narrates in real-time. An agent that respects attention is one whose voice you trust at Tier 10.

06

No single agent mints a credential.

Weighted Consensus is shown transparently — per-agent weights, scores, threshold. The Auditor's 40% weight is the heaviest because its evaluation is most insulated from social pressure.

07

Help has a visible price.

The 180s hint shows its cost. The Invigilator's L3 meta-help reaffirms structure without solving the problem. Hard-Gate Preemption can fire without warning if telemetry justifies it. Informed agency, not surveillance.

08

Career memory must be honest.

Vector cosine ≥ 0.65 threshold for any Mentor recall — below it, the Mentor stays silent. Every recalled artifact is a real sealed Vault record with a real ledger hash. The memory's authority depends on never inventing a recall.

09

The Review is the council's reconciliation.

All four voices stack in council order — Auditor forensic, Invigilator behavioral, Chaos dispatch summary, Mentor constructive. The credential's weight comes from seeing the consensus broken into its components.

10

Voice is a measurement surface, not a convenience.

PAT-009's Vocal Reasoning Trace captures whether the user articulated their reasoning aloud — directly measuring the verbal direction skill professional engineers actually need. The Technical Lexicon binds verbal vocabulary to the user's specific ontology nodes. Voice is opt-in, fully replaceable by text, but when used it's a real evidence channel. This is what differentiates Tenured AI's voice from "talk to a chatbot."
